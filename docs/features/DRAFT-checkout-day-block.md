# 체크아웃 날 수동 블락 (checkout-day-block) 스펙

## 요약
체크아웃만 있고 체크인이 없는 날(= 그날 밤이 비어 있는 날)에도 셀 상세에서 "🔒 이 날짜 블락하기" 버튼이 뜨도록 한다.

## 목적 및 배경
- **현재 증상**: 달력에서 체크아웃(아웃) 셀을 눌러 상세를 열면 예약 정보·비밀번호·메모만 보이고 **수동 블락 영역이 아예 없다**. 그래서 "손님이 나간 그날 밤"을 막을 방법이 상세 화면에는 없다.
- **원인**: `openDetail()`에서 블락 폼을 `else if(!allBks.length)` 조건으로만 보여준다. `findAllIn()`은 체크아웃 날도 예약에 포함(`cur <= cout`)하므로, 체크아웃 날은 "예약 있는 날"로 분류되어 블락 폼이 숨겨진다.
  - 위치: [app/JnJ booking/index.html:1811](../../app/JnJ%20booking/index.html#L1811)
- **왜 잘못된 판정인가**: 숙박 플랫폼의 달력은 **날(day)이 아니라 밤(night) 단위**다. 체크아웃 날은 그 손님이 자고 가는 밤이 아니므로 새 손님을 받을 수 있는 **빈 밤**이다. 에어비앤비도 체크아웃 날짜는 흰색(예약 가능)으로 표시한다. 즉 지금 코드는 "낮에 사람이 있었나"로 판단하는데, 실제로 막아야 할 대상은 "그날 밤"이다.
  - 이미 `docs/05-known-issues.md` 9번에 "체크아웃 날은 숙박 중에 포함 안 됨"으로 명시되어 있는 규칙인데, 블락 UI 조건만 이 규칙을 안 따르고 있다.
- **실사용 상황**: 오전에 손님이 나갔는데 그날 밤은 청소·수리·개인 사용 등으로 새 예약을 받지 않으려는 경우. 지금은 설정 패널의 블락 목록에서 날짜를 직접 입력해야만 가능하다.

## 기능 상세

### 사용자 시나리오
1. 8월 12일 401호 = 체크아웃만 있음(체크인 없음).
2. 달력에서 그 셀을 탭 → 상세 하단에 **🔒 수동 블락** 영역이 뜬다(시작일·종료일 모두 8월 12일 기본값).
3. 사유 입력(선택) 후 "🔒 이 날짜 블락하기" → 저장.
4. 셀이 **아웃 + 🔒 반반 셀**(`c-mix-out-bl`)로 바뀐다. 아웃 표시는 그대로 남아 청소 일정에는 영향이 없다.
5. 다시 그 셀을 누르면 기존 블락 수정/해제 폼이 뜬다(이미 구현되어 있는 경로).

### 동작 규칙 (블락 폼 표시 조건)
| 그날 상태 | 블락 폼 | 이유 |
|---|---|---|
| 예약 없음 | ✅ 표시 (현행 유지) | 빈 밤 |
| 체크아웃만 있음 | ✅ **표시 (이번 변경)** | 그날 밤은 빔 |
| 체크인 있음 | ❌ 숨김 | 그날 밤은 손님이 잠 |
| 아웃 + 인 (연박 교체) | ❌ 숨김 | 그날 밤은 손님이 잠 |
| 숙박 중 | ❌ 숨김 | 그날 밤은 손님이 잠 |
| 이미 블락된 날 | ✅ 수정/해제 폼 (현행 유지) | — |

- 오버부킹(같은 날 체크아웃 + 다른 예약 숙박 중)인 날은 **숨김**. 밤이 비어 있지 않기 때문.
- Airbnb 취소잔여 블락(`abBlocks`)도 위 판정에 동일하게 포함한다(그 블락의 마지막 날 = 체크아웃 취급 → 블락 가능).

### UI/UX
- 상세 화면 레이아웃·버튼 문구는 기존과 동일. **조건만 넓힌다.**
- 예약 정보 카드(체크아웃 안내 빨간 박스) 아래에 블락 영역이 붙는다.
- 기본 시작일 = 종료일 = 그날 (1박만 막힘).

## 기술 구현 방안

### 옵션 A — `openDetail()`의 표시 조건을 "밤 기준"으로 교체 (권장)
```js
// 그날 밤을 실제로 차지하는 예약이 하나라도 있는지
const nightTaken = allBks.some(b => !(b.coutY===y && b.coutM===m && b.coutD===d));
// ...
} else if (!nightTaken) {   // 기존: else if(!allBks.length)
```
- 수정 1줄 + 조건식 1줄. `allBks`는 이미 4개 플랫폼 + abBlocks를 다 합친 배열이라 별도 수집이 필요 없다.
- 체크아웃 날 + 다른 예약 숙박 중(오버부킹) → `nightTaken=true` → 자동으로 숨김. 정확.

### 옵션 B — `cellTypeFor()` 판정 결과로 조건 만들기
```js
const types=[ab,bk,tr,lv,abBlk 판정...];
if (types.every(t => t==='empty' || t==='checkout')) { 블락 폼 표시 }
```
- 달력 셀 색 판정과 같은 함수를 쓰므로 "보이는 것과 규칙이 같다"는 장점.
- ❗ 결함: `cellTypeFor`는 같은 플랫폼에서 `isOut`을 `occupied`보다 먼저 반환한다. 즉 **체크아웃 + 같은 플랫폼 다른 예약 숙박 중**이면 `'checkout'`으로 나와 오버부킹 날을 빈 밤으로 오판한다.

### 권장: 옵션 A
가장 적은 수정으로 정확하다. 옵션 B의 오판 위험이 없다.

## 결정 사항 (2026-08-05 사용자 승인)

### 1. 청소앱(JnJ) 표시 → **(b) 예약앱과 같은 반반 셀로 맞춘다**
청소앱의 `blockTypeFor()`는 `'start'` 구분이 없고 `'block'`만 반환해서, 체크아웃 + 블락 날이 `c-dual` 잡동사니 셀로 표시된다. 이를 예약앱과 동일한 `아웃 | 🔒` 반반 셀로 통일한다. 청소앱 `blockTypeFor` 1줄 + `bothLbl` 확장 + CSS 1개 + 판정 분기 추가.

### 2. 체크인이 있는 날 → **블락 불가 유지**
그날 밤에 손님이 자므로 막을 이유가 없다. 필요해지면 그때 별도 논의.
