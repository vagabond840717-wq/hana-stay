## 작업 단위 (순서대로)

### Task 1: 워커가 에어비앤비 예약에 끝 4자리를 싣는다
- 파일: `ical-proxy/worker.js` `parseIcal`
- 변경 내용:
  - 에어비앤비 `Reserved` 예약일 때, 접힌 줄을 편 블록(`uid` 뽑는 것과 같은 방식)에서
    `Phone Number (Last 4 Digits): ####` 를 찾아 `bk.ph = "1371"` 로 싣는다
  - 숫자 4개가 아니면 싣지 않는다 (형식이 바뀌면 조용히 빠짐 → 지금처럼 수동 입력)
  - ⚠ 기존 `DESCRIPTION` 검사(`desc.includes('airbnb.com/hosting/reservations')`)는 그대로 둔다
- 예상 코드: ~4줄

### Task 2: 끝 4자리가 다른 저장소로 새지 않게 막는다
- 파일: `ical-proxy/worker.js`
- 변경 내용 (`uid` 를 빼는 두 군데에 `ph` 도 같이 뺀다):
  - 알림 기억표 `bookingMap` (`const { uid: _u, ...plain } = b` → `{ uid: _u, ph: _p, ...plain }`)
  - 아카이브 병합 `merged.push(plain)` 같은 줄
- 확인만 (고칠 것 없음):
  - 원장 `buildDaySegs` — `{cin, cout}` 만 저장한다 ✓
  - 피드 변화 기록 `diffFeedShapes` — 날짜로만 비교하고 줄에 `ph` 를 안 넣는다 ✓
  - 내보내기 `exportIcal` — 날짜만 쓴다 ✓
- 예상 코드: ~2줄
- ⚠ `synced_bookings` 는 첫 동기화 때 모양이 바뀌어 **한 번 저장**된다. 그 뒤로는 변화 있을 때만 (KV 한도 원칙 유지)

### Task 3: 청소앱용 에어비앤비 피드 — 당일 아닌 예약의 설명 줄을 지운다 (`fix=ab`)
- 파일: `ical-proxy/worker.js` 프록시 경로 (`fixHost` 옆)
- 변경 내용:
  - `?url=<에어비앤비>&fix=ab` 일 때만 새 함수 `maskAbPhones(text)` 를 거친다
  - 접힌 줄을 편 뒤, 각 예약에서 **오늘(한국 날짜, `todayKST`)이 입실일도 퇴실일도 아니면 `DESCRIPTION` 줄을 통째로 지운다**
    - 전화 줄만 골라 지우지 않는 이유: 에어비앤비가 문구를 바꾸면 번호가 그대로 새어 나간다. 통째로 지우면 안전하다
    - 청소앱은 `DESCRIPTION` 을 안 읽는다 (확인함: `SUMMARY`·`DTSTART`·`DTEND` 만) → 달력 표시 무영향
  - 오늘이 입실·퇴실일인 예약은 그대로 둔다 → 그 손님 번호만 청소앱에 간다
  - ⛔ `fix` 없는 `/?url=` 는 지금처럼 원본 그대로 (진단 1번 '원본 대조' 보존)
  - ⛔ 오류가 나면 원본을 주지 말고 **설명 줄을 전부 지운 판**을 준다 (실패해도 번호가 새지 않게)
- 예상 코드: ~20줄

### Task 4: 예약앱 — 자동 번호 표시 + 교대 날 두 손님
- 파일: 예약앱 `index.html` `openDetail` 비밀번호 칸
- 변경 내용:
  - 비번 칸을 **손님별 상자**로 만든다:
    - 그날 나가는 예약과 들어오는 예약이 둘 다 있고 서랍이 다르면 → **두 상자를 같은 크기로** (위: 나가는 손님, 아래: 들어오는 손님)
    - 그 밖의 날 → 지금처럼 한 상자 (첫 예약 서랍 — 동작 불변)
  - 각 상자: 손으로 넣은 번호가 있으면 그 번호(지금 화면 그대로) + 맨 아래 `✈ 전화번호 끝 4자리: 1371` 한 줄
    / 없고 `ph` 가 있으면 `ph` 를 크게 + `✈ 전화번호 끝 4자리 (자동)`, `삭제` 버튼 없음
  - `수정`·`삭제`·이전 번호 `✕` 는 상자마다 자기 서랍에 쓴다 (지금 `pwKey` 한 개 → 상자별 키)
- 예상 코드: ~50줄 (비번 HTML 만들기 + 버튼 연결을 상자 단위로)
- ⚠ 10/01 교훈: `✕` 에 메모 버튼 모양을 빌려 쓰면 메모 동작이 덮어쓴다 → 비번 전용 클래스만 쓴다

### Task 5: 청소앱 — 당일에만 보이기 + 자동 번호
- 파일: 청소앱 `index.html`
- 변경 내용:
  - `fetchIcal` (에어비앤비) 주소에 `&fix=ab` 를 붙인다
  - `parseIcal` 에서 `Phone Number (Last 4 Digits)` 가 있으면 `ph` 로 싣는다 (Task 1 과 같은 규칙)
  - `pwBox` 공개 조건 = **고른 날짜가 오늘(기기 날짜)** 이고 그 상자가 **체크인 또는 체크아웃**(`role` in/out)
    - 아니면: 번호 자리에 `당일 공개` 만, `수정`·`삭제`·이전 번호 **전부 숨김**
    - 손으로 넣은 번호도 같은 규칙 (10/17 결정). 부킹·트립·리브·블락 서랍 전부
    - 교대 날엔 지금도 '아웃'·'인' 상자가 나란히 → 둘 다 공개
  - 공개 상자에 손 입력 번호가 없고 `ph` 가 있으면 `ph` + `(자동)` 표시
  - 오늘 날짜는 `getFullYear/getMonth/getDate` (#30 — `toISOString` 금지)
- 예상 코드: ~20줄

## 롤백 방법
- 저장소마다 위 커밋으로 `git revert` → 푸시 (= 즉시 배포)
- 저장 데이터를 새로 만들거나 바꾸지 않으므로 **되돌릴 데이터가 없다.**
  `synced_bookings` 의 `ph` 는 워커를 되돌리면 다음 동기화(5분)에 사라진다
- 워커만 되돌리고 청소앱을 그대로 두면 `fix=ab` 가 무시돼 원본이 간다 → **청소앱 화면 규칙(당일 공개)은 그대로 유지**된다

## 예상 주의사항
- #2 (같은 판정 두 곳) — 끝 4자리 뽑는 규칙이 워커 `parseIcal` · 청소앱 `parseIcal` 두 곳. 정규식을 똑같이

  손 입력 번호는 `/extra` 가 열려 있어 막지 못한다 → 별도 '예약앱 전용 열쇠' 작업
