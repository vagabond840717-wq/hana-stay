## 설계 확정

### 상태 저장 — KV `tr_daylock` (워커만 쓴다)

```js
{
  day:  "20260902",                                  // KST 오늘. 롤오버 감지용
  seen: { "402 jnj": false, "601 jnj": false },      // 안전창 마지막 관측: 그날 밤이 덮여 있었나
  fake: { "402 jnj": { night: "20260901", min: 1080 } }  // 가짜 판정 + 잠긴 밤 + 감지 시각(KST 분)
}
```

**`fake`는 '오늘'이 아니라 '잠긴 밤'을 기억한다.** 자정을 넘겨도 교정이 유지돼야 하기 때문이다.

> 실측: 어젯밤 잠금은 `9/1 18:00`에 생겨 `9/2 07:00`까지 살아 있다.
> `day` 기준으로 만들면 자정에 초기화돼 **새벽 0~7시가 다시 틀리게 된다** (사용자가 본 시각이 01:11이었다).

`fake` 항목은 **피드가 그 밤을 더 이상 덮지 않으면 스스로 사라진다** (07:00 해제 시 자동 정리).
안전장치로 잠긴 밤이 `어제`보다 오래되면 버린다.

### 상수

```js
const SAFE_FROM_MIN = 7*60 + 30;   // KST 07:30 ─ 안전창 시작 (트립이 팻말을 안 거는 시간)
const SAFE_TO_MIN   = 17*60 + 30;  // KST 17:30 ─ 안전창 끝 (17:59:59 잠금 전)
const LOCK_FROM_MIN = 18*60;       // KST 18:00 ─ 자물쇠 2 시작
const LOCK_TO_MIN   = 18*60 + 10;  // KST 18:10 ─ 크론 지연 여유 (실측 18:00:57~18:01:01)
```

### 뺄셈 규칙 (검증 완료)

```
[9/1, 9/11) − 9/1밤  =  [9/2, 9/11)               ← B 입실 쪽 (이번 건)
[8/10,8/13) − 8/12밤 =  [8/10,8/12)               ← C 퇴실 쪽 (#28)
[8/10,8/15) − 8/12밤 =  [8/10,8/12)+[8/13,8/15)   ← D 양쪽 (경계 복원)
[9/1, 9/2)  − 9/1밤  =  (사라짐)                   ← A 홀로
```

## 작업 단위

### ▣ A단계 — 장부 오염 정지 (워커, 화면 무변화)

#### Task A1: 판정 코어
- **파일**: `worker.js`
- **신설**:
  - `kstNow()` — `todayKST()` + 자정부터 지난 분
  - `coversNight(segs, ms)` — 밤 `[ms, ms+1일)` 이 조각에 덮이는가 (`cin <= ms < cout`)
  - `subtractNight(segs, ms)` — 그 밤만 빼고 앞뒤 조각을 남긴다. 빈 조각은 버린다
  - `updateDaylock(env, synced)` — 상태 갱신 + 자물쇠 1·2 판정. 내용 무변경이면 **KV write 생략**
  - `applyDaylock(synced, st)` — `tr` 만 뺄셈 적용. 다른 플랫폼·`ab` 블락은 **손대지 않는다**
- **판정 조건** (둘 다 만족해야 `fake` 등록):
  ```
  자물쇠 1:  st.seen[room] === false          (안전창에 그 밤이 비어 있었다)
  자물쇠 2:  LOCK_FROM_MIN <= t.min <= LOCK_TO_MIN   (18:00~18:10 차례에 처음 감지)
  ```
  `st.seen[room]` 이 `undefined` 면(안전창에 피드를 못 받음) **교정하지 않는다**
- **예상 라인**: ~90줄

#### Task A2: 장부 병합 전 적용
- **파일**: `worker.js` `syncAllRooms()`
- **변경**: `roomResults` 합친 직후 `updateDaylock` 호출 → `newArchive[*].tr` 에 뺄셈 적용 → 기존 병합 로직 그대로 통과
- **"긴 쪽 남기기" 규칙은 건드리지 않는다.** 가짜가 안 들어오면 그 규칙은 다시 100% 정확하다
- **예상 라인**: ~10줄
