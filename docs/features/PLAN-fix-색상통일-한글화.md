# 색상 통일 + 셀 글씨 한글화 — 구현 계획

## 문제 1 — 색상 불일치
같은 호실인데 청소 앱과 예약 앱의 호실 색이 다름.
- 청소 앱: 파스텔 계열 (라임그린, 민트 등)
- 예약 앱: 진한 계열 (빨강, 파랑 등)
→ 예약 앱 색상 기준으로 통일

## 문제 2 — 셀 글씨 영어
예약 앱 달력 셀 안에 `out` / `in` 영어로 표시됨.
청소 앱은 `아웃` / `인` 한글로 표시됨.
→ 예약 앱도 한글로 변경

### Task 2 — 청소 앱 기존 호실 색 자동 마이그레이션
기존에 저장된 호실 색이 옛날 팔레트라면 새 팔레트로 자동 변환.
- **파일**: `app/JnJ/index.html`
- **위치**: `loadRooms()` 함수 안
- **내용**: 로드 시 구 색상이면 새 색상으로 교체 후 저장

구 색상 → 새 색상 매핑:
```

#6ecf8f → #1a6fcc  (1번)
#5bc8d8 → #7c3aed  (2번)
#7fa8f5 → #d4571e  (3번)
#c07aee → #22a06b  (4번)
#f07cc8 → #f59e0b  (5번)
#f0b35b → #ec4899  (6번)

```

### Task 3 — 예약 앱 셀 글씨 한글화
- **파일**: `app/JnJ booking/index.html`
- **위치**: 716번째 줄 `io()` 함수
- **변경 전**:
  ```js

  ```

