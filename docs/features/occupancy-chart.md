# 점유율 그래프 뷰 (occupancy-chart) 스펙

## 요약
예약앱 통계(점유율 탭)에 월별 평균 점유율 막대그래프를 추가하고, 막대 선택 시 해당 월의 숙박 박수·주중/주말 분해·호실별 상세를 한눈에 보여준다.

## 목적 및 배경
기존 통계 뷰는 호실 9개 × 12개월 = 숫자 108개의 그리드라 "이번 달에 전체적으로 얼마나 찼는지", "성수기/비수기 패턴"을 즉시 읽기 어려웠다.
막대그래프로 월별 흐름을 먼저 보여주고, 관심 있는 달을 눌러 상세(박수, 주중/주말)로 내려가는 2단 구조로 바꿨다.

## 기능 상세

### 사용자 시나리오
- 📊 통계 → 점유율 탭 진입 시 상단에 12개월 막대그래프가 먼저 보임 (기본 선택: 이번 달)
- 막대를 탭하면 그 달의 요약 카드 + 호실별 상세가 아래에 표시됨
- 플랫폼 탭(전체/✈/🏨/🌐/🏡) 전환 시 그래프·상세 모두 즉시 재계산 (선택 달 유지)
- 기존 그리드(표)는 그래프 아래에 그대로 유지 (스크롤로 접근)

### UI 구성 (위→아래)
1. **월별 막대그래프**: 12개월(기존 그리드와 동일한 범위), 막대 높이 = 9개 객실 평균 점유율
   - 값 라벨은 선택 달·최고 달·최저 달에만 표시 (동률이 여러 달이어도 각 1개만 — first-occurrence 기준)
   - 데이터 없는 달: 막대 없이 회색 "—"
   - 선택 막대는 진한 네이비(`var(--navy)`), 나머지는 연한 파랑(`#93c5fd`)
2. **요약 카드 4개** (선택 달 기준):
   - 평균 점유율: `58%` (객실 N개 평균)
   - 객실당 평균 숙박: `17.9박` (31일 중)
   - 총 숙박: `161박` — 부제 `주중 98박 · 주말 63박`
   - 주중/주말 점유율: `49% / 78%`
3. **호실별 가로 막대**: 등록 순서, 호실명 + 막대(주중=연한 파랑 / 주말=진한 네이비 분리) + `N박 · P%`
4. **기존 그리드**: 변경 없음, 청소비용 탭 전환 시 그래프 영역은 비워짐

### 동작 규칙
- **주말 = 금·토 밤** (`getDay()`가 5 또는 6), 주중 = 일~목 밤
- 박수 계산은 기존 `calcOccupancy`와 동일 기준: cin 포함, cout 미포함 (그 날짜의 밤을 셈)
- 총 숙박·주중/주말 박수는 **9개 객실 합산 기준** (사용자 확정: 객실당 평균이 아님)
- 월 경계 걸친 예약: 날짜 단위 순회 방식이라 자동 처리 (기존과 동일)
- 블락 제외: 아카이브 자체가 블락 제외 저장이므로 추가 처리 불필요
- 청소비용 탭은 이번 범위 밖 (변경 없음)

## 기술 구현
- 방식: HTML div + flexbox 막대 (외부 라이브러리 없음), 기존 통계 그리드와 동일한 템플릿 문자열 + innerHTML 패턴
- `calcOccupancyDetail(roomName, platform, year, month)` 신설 (L2096 부근, `calcOccupancy` 바로 아래)
  - 반환: `{ nights, wkendNights, total, wkendTotal, noData }`
  - `wkdayNights = nights - wkendNights`, `wkdayTotal = total - wkendTotal`는 호출부에서 파생 계산 (함수 반환값에는 없음)
  - 기존 `calcOccupancy`는 그대로 유지 (기존 그리드가 계속 사용)
- `renderOccupancy()` 확장: `months` 배열 계산 직후 그래프+요약+호실별 막대 HTML을 `#statsChartArea`에 렌더, 그 아래 기존 표(`#statsGrid`)는 그대로
- 상태: `statsSelMonth = {y, m}` 전역 변수, `openStatsPanel()`에서 패널 열 때마다 `null`로 초기화 → 항상 이번 달부터 시작
- `renderCleaningStats()` 진입 시 `#statsChartArea`를 비움 (그래프는 점유율 탭 전용)

## 제약 및 주의사항
- 월 값 0-indexed 주의 (`getDay()`는 요일이라 별개 — 혼동 금지)
- `renderOccupancy()`는 innerHTML 전체 교체 방식 → 그래프 막대 클릭 리스너도 매 렌더 후 재등록
- 달력 `render()`/`attachCellClicks()` 체인과 무관 — 통계 오버레이 내부만 변경
- 호실명 변경 시 이력 고아 문제(known-issues #1)는 기존과 동일하게 이번 범위 밖
